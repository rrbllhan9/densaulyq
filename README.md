# 🌿 Спокойно (Densaulyq) — мед-помощник для тревожных пациентов

Веб-приложение, которое помогает разобраться с симптомами и записаться к врачу **без единого звонка** — для тех, кому тревожно обращаться за медицинской помощью.

> Это общие подсказки, а не замена врача. При неотложном состоянии — бесплатный номер **103**.

## Почему это важно

Многим людям страшно звонить в клинику, описывать симптомы незнакомому человеку по телефону и «отвлекать врача по пустякам». Из-за этого визит откладывается, а тревога растёт. «Спокойно» убирает этот барьер: тёплый чат, понятные подсказки и запись онлайн.

## Что умеет

- 💬 **Чат-триаж на 10 групп симптомов** — головная боль, температура, тревога и панические атаки, бессонница, горло, живот, спина, кашель, головокружение, аллергия. Распознаёт жалобу своими словами.
- 🚨 **Красные флаги** — признаки неотложного состояния (боль в груди, удушье, потеря сознания) распознаются в первую очередь и сразу показывают кнопку «Позвонить 103».
- 🫁 **«Подышим вместе»** — встроенное дыхательное упражнение 4–4–6 с анимированным кругом при тревоге и бессоннице.
- 🗺️ **Карта врачей** (Алматы) — геолокация «кто ближе», рейтинги, отзывы, цены.
- 🎯 **Умный подбор** — после триажа карта открывается уже с нужными специалистами.
- 📅 **Запись без звонка** — выбор времени в пару кликов, либо онлайн-консультация.
- 💊 **Безрецептурные средства** с дозировками и поиском на Kaspi.
- 🕊️ **Спокойный дизайн** — тёплая палитра, мягкие анимации, поддержка `prefers-reduced-motion`.

## Технологии

- **React 18 + Vite** — быстрый SPA
- **Leaflet / react-leaflet + OpenStreetMap** — карта без платных ключей
- **Триаж работает прямо в браузере** — без бэкенда, без платных API, полностью бесплатно
- CSS Modules, дизайн-система на CSS-переменных

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # продакшен-сборка в dist/
```

## Статус

Прототип, созданный на хакатоне. Данные о врачах — демонстрационные.
