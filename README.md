# Densaulyq

Медицинский помощник для людей, которым тревожно обращаться к врачам.

Проект сделан на AI ML хакатоне от KIMEP.

**Живая версия:** https://rrbllhan9.github.io/densaulyq/

> Приложение даёт общие подсказки и не заменяет врача. При неотложном состоянии — бесплатный номер 103.

## Идея

Многим людям по-настоящему страшно позвонить в клинику: описывать симптомы незнакомому человеку, слышать усталый голос в трубке, чувствовать, что «отвлекаешь по пустякам». Визит откладывается неделями, состояние и тревога тем временем растут.

Densaulyq убирает этот барьер. Человек описывает жалобу своими словами в спокойном чате — и получает понятный ответ: что можно сделать прямо сейчас, к какому врачу стоит сходить и как записаться к нему онлайн, не совершив ни одного звонка.

## Что умеет

**Чат-триаж на 10 групп симптомов.** Головная боль, температура, тревога и панические атаки, бессонница, горло, живот, спина, кашель, головокружение, аллергия. Жалобу можно писать своими словами — «голова раскалывается со вчера» распознается так же, как «болит голова».

**Красные флаги.** Признаки неотложного состояния — боль в груди, удушье, потеря сознания — распознаются в первую очередь. Вместо советов человек сразу видит крупную кнопку «Позвонить 103».

**Дыхательное упражнение «Подышим вместе».** При тревоге и бессоннице появляется анимированный круг, который задаёт ритм дыхания 4–4–6: вдох, пауза, длинный выдох. Длинный выдох физиологически успокаивает нервную систему.

**Карта врачей Алматы.** Геолокация показывает, кто ближе; у каждого врача — рейтинг, отзывы, цена приёма и свободное время.

**Умный подбор.** После триажа карта открывается уже отфильтрованной: пожаловались на тревогу — увидите психотерапевта и терапевта, а не весь список.

**Запись без звонка.** Выбор времени в пару кликов либо онлайн-консультация в чате.

**Безрецептурные средства** с дозировками и поиском в аптеках через Kaspi.

**Спокойный дизайн.** Тёплая палитра, мягкие анимации, уважение к настройке `prefers-reduced-motion` — для тех, кому спокойнее без движения на экране.

## Технологии

React 18 + Vite, карты Leaflet и OpenStreetMap без платных ключей. Триаж работает прямо в браузере — без бэкенда и без платных API, полностью бесплатно.

## Запуск

```bash
npm install
npm run dev
```
